# Playbook outline

```
1. Who we sell to
   - ICP (one page), disqualifiers
   - Personas: economic buyer, champion, evaluator, user, blocker
2. Why they buy
   - Value proposition, three pillars with proof
   - Persona messaging (one page)
3. How deals move
   - Stages with buyer-based exit criteria
   - Qualification checklist
4. Plays (one page each)
   - Inbound follow-up, cold outbound, discovery, demo, multi-threading,
     proposal, negotiation, close, handoff to customer success
5. Objections (top ten with answers and proof)
6. Competitors (one battlecard each)
7. Tools and hygiene (what to log, when)
8. Metrics (baseline, target, what to do when off)
9. Learning log (what changed, when, why)
```

## Stage table example

| Stage | Buyer exit criterion | Typical conversion to next |
| --- | --- | --- |
| Meeting booked | Buyer accepted a meeting about a named problem | 75-85% held |
| Discovery complete | Buyer confirmed problem, impact and decision process | 40-60% |
| Evaluation | Buyer agreed success criteria and joined a demo or trial | 50-60% |
| Proposal | Economic buyer reviewed the proposal | 50-65% |
| Commit | Buyer started the paper process (security, legal, procurement) | 80-90% |
| Closed won | Signed | |

## One-page play template

```
Play: <name>
When: <trigger or stage>
Goal: <buyer outcome by the end>
Steps: <3-6>
Assets: <emails, decks, documents>
What good looks like: <the bar>
Common mistake: <the trap>
```
