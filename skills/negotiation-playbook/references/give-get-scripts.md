# Give-get scripts and pressure tactics

## Conditional trades

- "If we can get to that number, can you commit to two years?"
- "I can include the extra seats if we can sign by the 28th so your team starts on the 1st."
- "We could move to quarterly payments if the term is annual."
- "If price is the blocker, we could start with the core team and add the rest in Q3 at today's rate."

## Pressure tactics and responses

| Tactic | Response |
| --- | --- |
| "Your competitor is half the price." | "They may be. Can we compare what's included line by line? If they're a better fit, I'll say so." |
| "We need 30% off or no deal." | "Help me understand what the 30% solves: budget this year, or total cost? There may be a better way to get there." |
| "Procurement requires a discount." | "Understood. What else does procurement value: term, payment schedule, a case study? Let's find the trade." |
| "Sign today and we'll do it." (they want a last-minute cut) | "I'd rather get it right than rushed. What would make this a clear yes?" |
| Silence after your number | Wait. Don't fill it with a lower number. |
| "Send your best and final." | "Here's the best version of the proposal. If something specific blocks a yes, tell me and I'll see what can move." |
| Bringing a new decision-maker at the end | Restate the agreed value and outcomes before discussing price again. |

## Concession pattern

| Step | Example |
| --- | --- |
| First | 10% for a two-year term |
| Second | 5% more for annual prepay |
| Third | 2% for signature by a date tied to their go-live |
| Then | Hold. Offer non-price items (onboarding, training) if anything |

## Written summary template

```
Agreed: <price, term, scope, payment>
Open: <items, owner, date>
Conditions: <what each concession depends on>
Next step: <who, what, when>
```
