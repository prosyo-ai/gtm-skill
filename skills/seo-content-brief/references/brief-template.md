# SEO brief template

```
Keyword: <primary>           Secondary: <3-6 variants>
Intent: informational / commercial / transactional
Audience: <role, situation>
Angle: "The <format> that <difference> for <audience>"
Format: guide / list / template / tool / comparison / landing page
Length guide: <range, set by what it takes to answer, not by competitors>

Title tag (≤60): <...>
Meta description (≤155): <...>
URL: /<short-slug>/
H1: <...>

Outline:
H2 <section> - must say: <one line> - answer first sentence: <...>
  H3 <...>
H2 ...

Questions to answer: <5-10, each mapped to a section>
Entities and terms: <...>
Original value: <data / template / screenshots / expert quote>
Internal links out: <3-6 pages with anchor text>
Internal links in: <pages that should link here>
Schema: <FAQPage / HowTo / Article / SoftwareApplication>
CTA: <primary + placement> | Secondary: <...>
Success: <rank target, traffic, conversions>
Refresh: <when to review>
```

## Intent to CTA map

| Intent | Example query | Fitting CTA |
| --- | --- | --- |
| Informational | "what is lead scoring" | Template or checklist download |
| How-to | "how to warm up a domain" | Free tool or step-by-step checklist |
| Commercial list | "best cold email tools" | Comparison table, free trial |
| Comparison | "x vs y", "x alternatives" | Side-by-side, migration help, demo |
| Transactional | "cold email template" | Instant copy, then a related product CTA |

## Writing rules to hand the writer

- Answer the section's question in the first sentence; then explain.
- Use the reader's terms; define jargon once.
- Short paragraphs, tables for comparisons, numbered steps for processes.
- Real examples and numbers beat adjectives.
- Date-sensitive facts carry a "last checked" note in the brief so they get refreshed.
