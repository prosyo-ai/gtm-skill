# Example reference page

Reference pages hold the depth a skill's body points to: full rubrics with real numbers, worked examples, templates, channel variants and edge cases. The body says when to read each one ("Read references/<this-file>.md for the scoring rubric").

## Shape that works

- A title that says what is inside.
- Tables for rubrics and thresholds.
- At least one worked example from start to finish.
- Edge cases and what to do about them.

Keep each page focused on one topic. Two or three focused pages beat one long one.
