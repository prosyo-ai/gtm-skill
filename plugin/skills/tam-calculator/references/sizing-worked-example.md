## Capacity check

- 4 AEs, each can run 60 qualified opportunities a year.
- Win rate 25%.
- Wins per year: 4 × 60 × 0.25 = 60. Over 3 years with hiring to 8 AEs: about 270 wins.
- SOM accounts implied by the table: 248 + 38 + 21 = 307. Close to capacity, so SOM holds. If it had implied 1,000 accounts, it would need cutting.

## Coverage check

- SAM accounts: 4,260. Contacts per account: 3. Total: about 12,800 contacts.
- 3 SDRs each start 600 new contacts a month: 1,800 a month.
- Months to touch the full SAM once: about 7. The team will need re-engagement plays and the 100+ segment (SSO) within a year.
