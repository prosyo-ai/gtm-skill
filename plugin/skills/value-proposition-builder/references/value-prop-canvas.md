# Value proposition canvas

## The canvas

| Box | Question | Answer |
| --- | --- | --- |
| Who | Which buyer, at which kind of company, in which situation? | |
| Job | What are they trying to get done? | |
| Today | How do they do it now (the alternative)? | |
| Pain | What is costly, slow, risky or annoying about today? | |
| Outcome | What does success look like, in their words? | |
| Unique | Why can only we deliver it this way? | |
| Proof | What evidence supports it? | |

## Worked example: scheduling for multi-location dental groups

| Box | Answer |
| --- | --- |
| Who | Operations leaders at dental groups with 10-60 locations |
| Job | Fill every chair every day across locations |
| Today | Each location schedules on its own; the ops team stitches it together in spreadsheets |
| Pain | Empty chairs at one site while another turns patients away; Monday reports are already out of date |
| Outcome | "I can see and fill every chair across the group from one screen" |
| Unique | Group-level schedule that moves patients and staff across nearby locations automatically |
| Proof | Northwind Dental: chair utilisation from 71% to 86% in 90 days |

One-liner: "Fill every chair across every location, without the Monday spreadsheet."

Paragraph: "Dental groups lose revenue when one office is overbooked and the next one sits empty. <Product> puts every location's schedule in one view and moves patients and staff to where there is capacity. Northwind Dental went from 71% to 86% chair utilisation in 90 days."

## Phrases to replace

| Instead of | Say |
| --- | --- |
| All-in-one platform | What it replaces: "your scheduling spreadsheet and three portals" |
| AI-powered | What the AI does: "suggests the best open slot nearby" |
| Streamline workflows | The specific time saved: "Monday reporting takes 10 minutes" |
| Best-in-class | The proof: a customer and a number |
| Enterprise-grade | The specific thing: "SSO, audit logs, data stays in the region" |
