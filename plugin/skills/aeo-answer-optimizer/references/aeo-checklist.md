# AEO page checklist

## Content

- [ ] The page's main question is answered in the first 1-2 sentences.
- [ ] Each H2 is a question or a clear topic, and its first sentence answers it.
- [ ] Facts are stated plainly: "X is a <category> for <who>. It costs <price> per <unit>."
- [ ] Product name, category and audience are used consistently with other pages.
- [ ] Comparison tables have explicit criteria and honest "best for" rows.
- [ ] Numbers carry a source or a date.
- [ ] A short FAQ answers the 5-8 most common questions in 40-80 words each.
- [ ] No important text exists only in images, tabs that need clicks, or scripts.

## Technical

- [ ] Server-rendered HTML with the main content present on load.
- [ ] Organization schema (name, logo, sameAs profiles).
- [ ] SoftwareApplication or Product schema with offers where pricing is public.
- [ ] FAQPage schema matching the visible FAQ.
- [ ] Article schema with author and dates on content pages.
- [ ] Sitemap includes the page; canonical is correct.
- [ ] `robots.txt` allows the assistants' crawlers the business wants to be cited by.
- [ ] `llms.txt` at the root lists the key pages with one-line descriptions.

## Corroboration sources to check

- Review and software directory profiles.
- Integration partners' listing pages.
- Community answers and forum threads about the category.
- Articles and lists that rank for "best <category>" queries.
- The company's own social profiles and bios.

Each one should describe the product the same way as the fact sheet.
