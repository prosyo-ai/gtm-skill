## Typical durations (mid-market, adjust per buyer)

| Step | Typical time |
| --- | --- |
| Security questionnaire + review | 1-3 weeks |
| Legal review of standard terms | 1-2 weeks |
| Legal review with redlines | 2-4 weeks |
| Procurement and vendor setup | 1-3 weeks |
| Budget approval outside the cycle | 2-6 weeks |

## Critical path example

Security (3 weeks) → can run in parallel with business case (2 weeks) → legal (2 weeks) and procurement (2 weeks) in parallel → signature. Total 5 weeks minimum if security starts on day one; 7-8 if security starts after the business case. Start the security questionnaire as soon as the technical review is booked.

## Weekly review questions

- Which steps moved? Which slipped and why?
- Is any step missing a buyer-side owner?
- Does the signature date still support the go-live date?
